# FDE Design Docs

This directory contains product and market design documents for FDE.

- `fde-product-design.md` — canonical product-role design: what FDE must feel like, what the FDE Session owns, and what Phase 1 must prove.
- `fde-ecommerce-tcm.zh-CN.md` — China-market design: cross-border ecommerce operations as the primary vertical, TCM clinic operations as the secondary/shadow vertical.

Read order:

1. `fde-product-design.md` for the product role, session contract, and MVP acceptance bar.
2. `fde-ecommerce-tcm.zh-CN.md` for the China-market wedge, design-partner criteria, and vertical-specific guardrails.
3. `../PRD.md` or `../PRD.zh-CN.md` for the full roadmap, IR details, risks, and metrics.

Execution plans live in `docs/plans/`. Product plans should not be stored under `docs/superpowers/plans/`.
